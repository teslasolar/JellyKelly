# Jelly Kelly - Ocean Vibes

Jelly Kelly Auditory Repository — where the birdies sing and the jellyfish swing.

## Tracks

1. **Jelly Kelly** — The title track. Deep currents, floating melodies, and the pulse of the open sea.
2. **Gettin' the D** — Riding the tide. Raw energy crashing against the shore, sun on the horizon.

## About

Ocean-themed music project featuring an interactive web player with animated birdies, jellyfish, waves, and bubbles. Open `index.html` to dive in.
